## Display Styles

Choose from multiple display options to best suit your store design:

### Popup Modal
The most popular option - opens in an overlay window.

**Pros:**
- Doesn't interfere with product page layout
- Focuses customer attention on sizing
- Works well with all themes

**Configuration:**
- Modal size and position
- Animation style
- Background overlay
- Close button behavior

### Inline Display
Shows the size chart directly on the product page.

**Pros:**
- Always visible to customers
- No additional clicks required
- SEO-friendly content

**Configuration:**
- Position on page
- Collapsible sections
- Integration with product details

### Sidebar
Slides out from the side of the page.

**Pros:**
- Modern, mobile-friendly design
- Preserves page layout
- Smooth animations

**Configuration:**
- Side preference (left/right)
- Animation speed
- Overlay behavior

### Tab Integration
Adds a size chart tab to existing product tabs.

**Pros:**
- Integrates seamlessly with theme
- Familiar user interface
- Organized content presentation

**Configuration:**
- Tab label customization
- Position in tab order
- Icon selection
