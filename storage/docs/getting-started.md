# Getting Started

Welcome to the Size Chart Enhanced app! This guide will help you set up and configure your first size charts.

## Quick Start

Follow these steps to get your size charts up and running:

### 1. Installation
Once the app is installed from the Shopify App Store, you'll be redirected to the dashboard.

### 2. Create Your First Size Chart
1. Navigate to **Setup** in the sidebar
2. Click **Create Size Chart**
3. Choose your product category (clothing, shoes, accessories)
4. Add measurements using our table editor

### 3. Assign to Products
1. Select products during creation, or
2. Use **Assign to Products** feature later
3. Bulk assign using collections or tags

## Key Features

- **Multiple Display Styles**: Popup, inline, sidebar, tab integration
- **Responsive Design**: Optimized for all devices
- **Unit Conversion**: Automatic cm/inches conversion
- **CSV Import/Export**: Bulk manage your data
- **Theme Integration**: Works with any Shopify theme
